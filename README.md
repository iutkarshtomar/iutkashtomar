## ✦ Features

- **Living Aurora Background:** Custom WebGL fragment shader with domain-warped FBM aurora in violet, magenta, and electric blue.
- **Scroll-Scrubbed Portrait Render:** Eleven dynamic canvas render passes (Block → Halftone → ASCII → Dither) resolving into a portrait photo with scan-wipe animation.
- **Interactive Terminal:** Custom command-line interface in the *Now* section supporting quick commands (`help`, `whoami`, `edu`, `certs`, `quote`, `contact`).
- **Smooth Navigation & Kinetic Typography:** Driven by GSAP ScrollTrigger and Lenis smooth scrolling.
- **Modern Responsive Design:** Crafted with semantic HTML5, Vanilla CSS design tokens, and modular JavaScript without heavy frameworks.

## 🚀 Running Locally

To run the portfolio locally without any build steps or package managers:

```bash
# Using Python
python3 -m http.server 8000

# Open in your browser
open http://localhost:8000
```
